# Fusion Minerals

A static research site examining mineral supply chains, due diligence and human-rights risks relevant to emerging fusion technologies.

## View the site

The site is published with GitHub Pages:

<https://isislcn.github.io/fusion-minerals/>

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server. The site has no build step or package dependencies.

## Research scope

The site considers tungsten, lithium, lithium-6, beryllium and rare earths across mining, trade, refining, components and plant procurement. Evidence labels distinguish documented, reported and inferred claims. A reported risk in a region or material supply chain is not evidence that a specific fusion company sources from it.

See [Methodology](./index.html#methodology), [Limitations](./index.html#limitations) and [Sources](./index.html#sources) for scope and evidence notes.

## Publishing

Pushes to `main` deploy the root directory to GitHub Pages using the workflow in `.github/workflows/pages.yml`. The workflow enables Pages during its first deployment.
