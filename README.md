# Fusion Minerals

A static research site examining mineral supply chains, due diligence and human-rights risks relevant to emerging fusion technologies.

## View the site

The site is published with GitHub Pages:

<https://isislcn.github.io/fusion-minerals/>

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server. The site has no build step or package dependencies.

## Research scope

The site considers tungsten, lithium, lithium-6, beryllium and rare earths across mining, trade, refining, components and plant procurement. Evidence labels distinguish documented, reported and inferred claims. The Human cost page connects public reporting to material stages without attributing sourcing to a fusion buyer.

See [Methodology](./index.html#methodology) and [Sources](./index.html#sources) for scope, limitations and linked APA references.

## Publishing

Pushes to `main` deploy the root directory to GitHub Pages using the workflow in `.github/workflows/pages.yml`. The workflow enables Pages during its first deployment.
